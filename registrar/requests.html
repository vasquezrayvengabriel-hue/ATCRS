Request Processing Guidelines

  • Review the student's information and requested document before processing the request.
  • Confirm the payment status when a processing fee is required.
  • Check the required clearance information before approving the document request.
  • Update the request status as the document moves through the processing stages.
  • Confirm the document is ready before marking the request as released.
  • Keep clear notes for requests that require additional review or action.
