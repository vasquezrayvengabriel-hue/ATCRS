Document Processing Guidelines

Review the student's request, payment status, clearance information, and submitted details before approving an official school document.

Documents should only be marked as released after the required processing and approval steps have been completed.

Make sure the selected release method matches the student's request before completing the document release.

Release Checklist

Before Releasing a Document

  • Confirm the student's identity and Student ID.
  • Confirm that the correct document was requested.
  • Review the payment status.
  • Confirm that the required clearance has been completed.
  • Review the document processing status.
  • Confirm the selected release method.
  • Record the release date and any relevant notes.
